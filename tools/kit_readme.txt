OVERHEAT - PLAYTEST LAUNCHER
============================

1. Unzip this folder anywhere (Desktop is fine).
2. Double-click Overheat.exe. Windows may warn about an unknown app: More info > Run anyway.
   The launcher updates itself and downloads the newest game build every time it starts.
3. Pick a channel:
   STABLE  the tested build, for everyone.
   DEV     the newest build, for testers. Type your pilot name and paste the tester code you
           were given (it starts with OH-). Keep the code to yourself.
4. Press PLAY. CHECK FOR UPDATE fetches a build that came out while the launcher was open.
